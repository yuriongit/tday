# TDay - To-Do

## Commands

- [ ] ```tday new```
- [ ] ```tday ls```
- [ ] ```tday upd```
- [ ] ```tday rm```

- [ ] ```tday old ls``` for listing expired tasks
- [ ] ```tday old rm {#}```
- [ ] ```tday old done {#}```

expired tasks will list the actual date it was created
on and the time it was due at will show the overdue label
and the TTL.
